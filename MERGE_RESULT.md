# Bản ghép 2 project

Bản này lấy project `28-30` làm nền vì đã chứa các chức năng mới, đồng thời giữ lại file `src/main/resources/templates/booking/host_bookings.html` từ project `1` vì file này chỉ có ở project 1.

Đã giữ các chức năng của project 28-30:
- Task 28: đăng nhiều ảnh cho một căn nhà.
- Task 29: cập nhật trạng thái nhà theo từng giai đoạn thời gian.
- Task 30: lọc danh sách nhà theo trạng thái.

Lưu ý: môi trường hiện tại không có Internet nên Gradle không thể tải Gradle 9.5.1 để chạy test. Code chưa được xác nhận build bằng Gradle trong môi trường này.
